# Git Guide
*A beginner's guide to Git. No prior experience needed.*

## Curriculum

| # | Lesson | You'll learn | Key commands |
|---|--------|--------------|--------------|
| 01 | [What is Git?](01-what-is-git.md) | Version control, repositories, commits, why Git exists | none |
| 02 | [Setup](02-setup.md) | Install Git, set your name/email, check the version | `git --version`, `git config` |
| 03 | [Your first commit](03-first-commit.md) | Working directory → staging area → commit | `git init`, `git add`, `git commit` |
| 04 | [Inspecting your repo](04-inspecting.md) | Seeing what changed and what happened | `git status`, `git diff`, `git log` |
| 05 | [Undoing things](05-undoing.md) | Discarding changes, unstaging, fixing the last commit | `git restore`, `git commit --amend`, `git revert` |
| 06 | [Branches](06-branches.md) | Working on something without touching `main` | `git branch`, `git switch` |
| 07 | [Merging & conflicts](07-merging.md) | Combining branches and resolving conflicts | `git merge` |
| 08 | [Remotes & GitHub](08-remotes.md) | Pushing to GitHub, cloning, pulling | `git remote`, `git push`, `git pull`, `git clone` |
| 09 | [Good habits](09-good-habits.md) | `.gitignore`, good commit messages, small commits | none |
| | [Cheat sheet](cheatsheet.md) | Every command from this guide on one page | |
